## Τι κάνει το μοντέλο

Κάθε βακτήριο είναι ανεξάρτητος πράκτορας με μεταβολική ενέργεια, επίπεδο αντοχής και εξατομικευμένα όρια MIC (ελάχιστη ανασταλτική) και MBC (ελάχιστη βακτηριοκτόνος συγκέντρωση). Το περιβάλλον είναι δισδιάστατο πλέγμα 33×33 patches με θρεπτικά που αναπληρώνονται από τη βάση και αντιβιοτικό που εισέρχεται από την κορυφή, διαχέεται και αποδομείται. Τα κύτταρα τρέφονται, αναπαράγονται, μεταλλάσσονται, ανταλλάσσουν γονίδια αντοχής μέσω της εξωκυττάριας μήτρας (HGT) και πεθαίνουν από αντιβιοτικό ή εξάντληση.

Η εργασία ακολουθεί **προοδευτική προσθήκη μηχανισμών**: ξεκινά από μια ελάχιστη διαμόρφωση και προσθέτει έναν-έναν τέσσερις ρεαλιστικούς μηχανισμούς (κόστος αντοχής, κύτταρα persister, αποκλεισμό όγκου ανά patch, διάχυση θρεπτικών), ελέγχοντας σε κάθε βήμα ποια συμπεράσματα εξακολουθούν να ισχύουν. Όλες οι παράμετροι είναι αδιάστατες· ο χρόνος μετριέται σε ticks και οι αποστάσεις σε patches.

## Απαιτήσεις

- **NetLogo 7.0 ή νεότερο** — https://ccl.northwestern.edu/netlogo/ (το μοντέλο είναι αρχείο `.nlogox`, το νέο format του NetLogo 7· δεν ανοίγει σε NetLogo 6).
- **Python 3.10+** με `numpy`, `pandas`, `scipy`, `matplotlib` (μόνο για την ανάλυση).

## Εκτέλεση της προσομοίωσης

1. Ανοίξτε το `model/biofilm-antibiotic.nlogox` από το NetLogo (File → Open). Μην αντιγράψετε τον κώδικα σε κενό μοντέλο — οι sliders, οι switches και τα πειράματα BehaviorSpace βρίσκονται μέσα στο αρχείο.
2. Πατήστε **setup** και μετά **go**. Η οθόνη δείχνει το πλέγμα (θρεπτικά κάτω, αντιβιοτικό πάνω) και τα κύτταρα χρωματισμένα κατά αντοχή· τα νεκρά κύτταρα μένουν γκρι.
3. Οι sliders αντιστοιχούν στις παραμέτρους του Πίνακα 3.4 της εργασίας. Οι switches `hgt-enabled?`, `strong-penetration?`, `well-mixed?` ενεργοποιούν τα αντίστοιχα σενάρια· `max-cells-per-patch = 0` σημαίνει χωρίς αποκλεισμό όγκου.

## Εκτέλεση των πειραμάτων (BehaviorSpace)

Tools → **BehaviorSpace** → επιλέξτε πείραμα → **Run** → επιλέξτε **Table output** και αποθηκεύστε το CSV μέσα στον φάκελο `data/` με το προεπιλεγμένο όνομα (`biofilm-antibiotic <πείραμα>-table.csv`). Το script ανάλυσης αναγνωρίζει κάθε πείραμα από το όνομα του αρχείου.

| `4-strong-penetration` | 10 | HGT on/off × ισχυρή διείσδυση (2×2) | 4.4 (Πίν. 4.1, Εικ. 4.5) |

## Ανάλυση των αποτελεσμάτων

```bash
cd analysis
pip install -r requirements.txt
python run.py --data-dir ../data --out ../figures        # όλα τα πειράματα
python run.py --data-dir ../data --out ../figures --only 7 12   # μόνο τα πειράματα 7 και 12
python run.py --list                                      # ποιο αρχείο αντιστοιχεί σε ποια ενότητα
```

Το `run.py`:

1. Εντοπίζει όσα `*table.csv` υπάρχουν στον φάκελο δεδομένων και αναλύει μόνο τα αντίστοιχα πειράματα (τα υπόλοιπα τα προσπερνά — δεν χρειάζεται να έχετε και τα 19).
2. Παράγει τα γραφήματα κάθε πειράματος (`fig01_…png` κ.λπ.) στον φάκελο εξόδου.
3. Γράφει την πλήρη στατιστική αναφορά `stats_report.txt`: bootstrap 95% διαστήματα εμπιστοσύνης, Kruskal–Wallis, Mann–Whitney με διόρθωση Holm–Bonferroni, Cliff's δ με bootstrap ΔΕ και ελέγχους ισοδυναμίας TOST — τα ίδια νούμερα που αναφέρονται στο Κεφάλαιο 4.
4. Συγκρίνει το μοντέλο με δύο ανεξάρτητα μοντέλα αναφοράς: την αναλυτική λύση αντίδρασης–διάχυσης για το προφίλ του αντιβιοτικού και το λογιστικό μοντέλο πληθυσμού (ενότητα 4.7).

Πρόσθετες επιλογές: `--appendix` (τυπώνει και την αποσυρμένη ανάλυση του πειράματος 10), `--biofilm-thickness-um`, `--base-diffusion`, `--base-decay`, `--biofilm-depth` (παράμετροι της βαθμονόμησης κλίμακας, ενότητα 4.7). `python run.py --help` για τη λίστα.

Για να δείτε πώς αναλύθηκε ένα συγκεκριμένο πείραμα, ανοίξτε το αντίστοιχο αρχείο στο `experiments/` — είναι 20–50 γραμμές το καθένα και ακολουθεί την ίδια δομή: φόρτωση → υπολογισμοί και στατιστικοί έλεγχοι → γράφημα.

Τιμές `-999` στα CSV σημαίνουν «κανένα ζωντανό κύτταρο» και μετατρέπονται σε NaN από το script, ώστε η εξαφάνιση του πληθυσμού να μη συγχέεται με μηδενική αντοχή (ενότητα 3.8).
